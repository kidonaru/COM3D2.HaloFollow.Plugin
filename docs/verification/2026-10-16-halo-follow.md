# HaloFollow 実機確認結果（2026-10-16）

## 環境

- COM3D2.5（Unity 2022.3.62f2）、BepInEx 5.4.21、プラグイン 0.1.0.0（Debug ビルド）
- セーブスロット 46（2026-10-16 09:53 保存）をロードし、SceneDaily でストックメイド「柚鳥 ナツ」をメイド枠 1 に表示して確認した
- 装備: `trinity_sweets_halo_z3_hat_i_.menu`（`natu_halo.model`、スロット accHat、シェーダー COM3D2/MToon10）
- 確認は MCP `com3d25-devbridge` の `eval_csharp` / `watch_add` で行った。ずれは、代理ボーン `HaloFollow_Headset` と元の `Headset` のワールド位置・回転の差として測った。頭のスケール（`Bip01 Head` の lossyScale 平均）は約 1.062 で、cm 設定値はこの倍率でワールドへ換算される

## 確認中に分かったこと

- ゲームの待機モーション（WrapMode.Loop）の `AnimationState.time` は周回で巻き戻らず増え続ける
- 視線追従（`boHeadToCam`）が ON だと、30 fps でだけ角度のずれが 0.5 度ほど大きく出た（4.81〜4.91 度）。視線追従 OFF では 30/60/120 fps がそろうので、ゲーム側の視線追従がフレームレートで頭の回転そのものを変えているのが原因で、本プラグインの追従計算の差ではない
- メイドがフード付きの衣装を着ていると、ゲーム側が帽子スロット（accHat）を非表示にするため、ヘイローは表示されず追従もしない（非表示の装備は更新を飛ばす仕様どおり）
- AnimationState のマネージド参照は列挙のたびに同じインスタンスが返る
- 設定ウィンドウは既定のスキンだと背景が半透明で、後ろのゲームの UI が透けて読みにくかった。背景を不透明にし、再起動後の実機で読めることを確認した

## 確認できなかったこと

- SceneEditor のタイムライン自体の再生・一時停止・シーク・ループ・連番出力。今回は SceneEditor が使うのと同じ `AnimationState` の speed / time 操作で模擬した。実際のタイムライン操作での確認は残っている
- SceneEditor の「キャラの影」の複製との組み合わせ
- 体型スライダーで頭のスケールを変えたときの見た目（換算式の値だけを確認した）
- 動画・連続画像での比較は作っていない。代わりに、追従 ON / OFF で同じ動きの同じ瞬間を撮った静止画を `images/` に置いた
