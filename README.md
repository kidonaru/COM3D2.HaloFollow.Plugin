## 概要

頭に固定されたヘイローなどの装備を、頭の動きに少し遅れて滑らかに追従させるプラグインです。

ヘイローは基準位置を中心に、いつも小さく上下に浮遊します。

- ヘイローは一つの剛体として動きます。輪の形・大きさ・材質・描画設定は変わりません
- 追従させる装備は、メイドごとにスロット（帽子なら `accHat`）で指定し、設定もメイドごとに保存します
- 位置と回転の追従は、別々に有効化・調整できます
- 位置と角度のずれには上限があり、急な動きでも頭から離れすぎません
- SceneEditor の再生・一時停止・コマ送り・シーク・ループ・連番出力に合わせて動きます
- モデルファイル・SceneEditor の保存内容・頭・髪・他の衣装は変更しません


## インストール方法

[Releases](https://github.com/kidonaru/COM3D2.HaloFollow.Plugin/releases)
から最新の`COM3D2.HaloFollow.Plugin-vX.X.X.X.zip`をダウンロードします。

zip解凍後、お使いのゲームに対応したフォルダの中身を、`Sybaris\UnityInjector`フォルダに配置してください。

- COM3D2 の場合: `UnityInjector`フォルダ
- COM3D2.5 の場合: `UnityInjector (COM3D2.5)`フォルダ

※両方を同時に配置しないでください。dllの内容が異なるだけで、ファイル構成は同じです。

各ファイルの説明:
- `COM3D2.HaloFollow.Plugin.dll`
  - プラグインの本体。

UnityInjector（Sybaris、または BepInEx の UnityInjectorLoader）が導入済みである必要があります。

以前の BepInEx 版を入れていた場合は、`BepInEx\plugins\COM3D2.HaloFollow.dll` を削除してください。残すと二重に動きます。


## アンインストール方法

1. `Sybaris\UnityInjector\COM3D2.HaloFollow.Plugin.dll` を削除します
2. 設定も消す場合は、`Sybaris\UnityInjector\Config\HaloFollow.xml` と `Sybaris\UnityInjector\Config\HaloFollow\` フォルダを削除します

モデルファイルは変更していないため、ほかに戻す作業はありません。


## 起動方法

ギアメニューの「HaloFollow」ボタンか `Ctrl` + `Shift` + `H` キーで、設定ウィンドウを開閉します。
（`Config/HaloFollow.xml` の `windowShortcut` を編集することでキーの変更も可能です。書式は `Ctrl+Shift+H` のように修飾キーとキー名を `+` でつなぎ、大文字小文字を区別します）

使い始めるには:

1. ヘイローを装備したメイドを表示します
2. 設定ウィンドウの「追従」タブで、メイドとヘイローのスロット（帽子なら `accHat`）を選び、「このスロットを追従させる」を ON にします


## 推奨プラグイン

単体で動作しますが、以下があると連携・補完されます。

- **SceneEditor**
  - 設定ウィンドウを SceneEditor のウィンドウとタブにまとめて（ドッキングして）表示できます
  - UI 倍率は SceneEditor の設定に従います
  - SceneEditor が無い場合は、独立したウィンドウとして動きます
- **Harmony**（BepInEx 同梱の `0Harmony.dll`）
  - 衣装の着替えの検知に使います
  - 無い場合も動きますが、着替え後の再検出が最大 1 秒遅れ、uGUI の画面を操作している間はヘイローが頭の最終姿勢より前に動くことがあります


## 機能詳細

### 共通

ウィンドウの最上段は全タブ共通です。

- **ヘイロー追従を有効にする**: 全体の切替です。無効にすると、通常の頭への固定追従に戻ります（メイドごとの設定は変わりません）
- **姿勢リセット**: すべての装備を現在の頭の姿勢へ即座に合わせ、追従の速度と浮遊を初期化します

変更はゲームを再起動せずに反映され、最後の変更から 1 秒後に保存されます。

### 追従タブ

1. **メイド**: 表示中のメイドから選びます
2. **スロット**: 追従させる装備のスロットを選びます（帽子なら `accHat`）
   - 候補は、装備中のスロットと、設定済みのスロットです。表示は「スロット: モデル名」です
   - 設定済みは先頭に並び、印が付きます（● 追従 ON、○ OFF。未装備なら「（未装備）」）
   - 体そのもののスロット（body・head など）は候補に出ません
   - 開いたときは、設定済みのスロット（無ければ `accHat`）が選ばれています
3. **このスロットを追従させる**: ON にすると、そのスロットの設定を作って追従を始め、下に設定欄が出ます。OFF は設定を残したまま止めます（OFF 中も設定欄は出て、編集・削除できます）
   - 右に状態が出ます（追従中 / 未装備 / 追従できない / OFF / 全体 OFF）。「追従できない」は、選んだボーンが装備に無いなどの理由で、詳しくはゲームのログに出ます
4. **追従ボーン**: モデルが頭に付くためのボーンを、そのスロットのメッシュが参照するボーンから選びます。既定は `Headset` です
5. 追従・浮遊・陰影・オフセットのスライダー（項目は「[メイドごとの設定](#メイドごとの設定)」）。右の「R」は 1 項目だけを既定値に戻します
6. **初期値に戻す**: 全項目を既定値に戻します（既定のボーン Headset が装備に無いときは、ボーンだけ今のまま残します）
7. **このスロットの設定を削除**: 設定ごと消して、頭への固定追従に戻します

### プリセットタブ

追従タブで選んでいるスロットの設定（ボーン・追従・浮遊・陰影・描画レイヤー・オフセット）を、名前を付けて保存・適用します。設定のあるスロット（追従の ON・OFF は問いません）が対象です。

- **保存**: 名前を入れて保存します。同じ名前があると「上書き」になります
- **適用**: 選んでいるスロットへ適用します。スロット名と有効・無効は変わりません。プリセットのボーンが適用先の装備に無いときは、ボーンだけ今のまま残します
- **削除**: 1 回押すと「確定」に変わり、もう一度押すと削除します
- **開く** / **更新**: 保存先のフォルダを開く / 一覧を読み直す

### 判定タブ

瞬間移動・コマ送り・シークの判定です。全メイド共通です（項目は「[判定の設定](#判定の設定)」）。

### 設定タブ

- **UI 倍率 %**: ウィンドウの拡大率です。SceneEditor がある間は SceneEditor の設定を書き換えます
- 開閉キーと、検出中の装備の一覧を表示します


## 保存先

| 内容 | 場所 |
| --- | --- |
| メイドごとの設定 | `Sybaris\UnityInjector\Config\HaloFollow\Maids\<メイドの guid>.xml` |
| プリセット | `Sybaris\UnityInjector\Config\HaloFollow\Presets\<名前>.xml` |
| 全体の設定（有効化・開閉キー・判定・ウィンドウ） | `Sybaris\UnityInjector\Config\HaloFollow.xml` |

BepInEx 版（0.1.0 の開発版）の `BepInEx\config\` の設定は引き継ぎません。

- 読めない設定ファイルは `.bak` へ退避し、既定値（メイドの設定なら設定なし）で始めます
- 同じ guid のメイドが 2 人いる場合は、設定を共有します


## 設定項目

### メイドごとの設定

スロットごとに保存します。

| 項目 | 既定値 | 内容 |
| --- | --- | --- |
| 有効 | ON | このスロットの追従を有効にする |
| 追従ボーン | Headset | モデルが頭に付くためのボーン |
| 位置の遅れ追従 / 位置の追従時間 | ON / 0.10 秒 | 0 秒で即時追従 |
| 回転の遅れ追従 / 回転の追従時間 | ON / 0.10 秒 | 0 秒で即時追従 |
| 最大位置ずれ | 5 cm | 本来の位置からの最大ずれ。遅れと浮遊を合成した結果にかかるため、遅れが上限に達している間は浮遊が削られる |
| 最大角度ずれ | 30 度 | 本来の角度からの最大ずれ |
| 位置オフセット / 角度オフセット | 0 | 基準位置・角度の追加オフセット（ボーンのローカル軸）。位置は ±10 cm、角度は ±30 度まで |
| 上下浮遊 | ON | 動いている間も浮遊する。OFF なら基準位置へ収束する |
| 浮遊の振幅（片側） | 1 cm | 全幅はこの 2 倍。0 で浮遊なし |
| 浮遊の周期 | 3 秒 | 1 往復の時間 |
| 浮遊の切替時間 | 0.3 秒 | 浮遊の ON / OFF やシークの後に、浮遊の強さを切り替える時間 |
| 陰影の濃さを上書きする / 陰影の濃さ | OFF / 0 | 主光源による陰影（ゲームの影ランプの暗さ・落ち影を含む）の濃さを、このスロットだけ上書きする。0 で影側も光側と同じ明るさになり暗くならない。1 より上は影が濃くなる。`_ShadeStrength` を持つシェーダー（MToonMaid の MToon10）で効き、持たないシェーダーでは何も変わらない。上書き中は MToonMaid の「陰影の濃さ」はこのスロットに効かない。追従が ON の間だけ有効 |
| 描画レイヤー | Character | Character はメイドと同じ（ゲームが付けたレイヤーのまま）。Default は背景の小物や ModItemExplorer の既定のモデルと同じレイヤー 0 に移す。SceneEditor のライトの照射対象やキャラの影などの扱いが、選んだ側に合わせて変わる。追従が ON の間だけ有効で、OFF にすると元のレイヤーに戻る |

距離（cm）は頭のスケールに合わせて換算します。体型スライダーで頭を大きくすると、ずれの上限や振幅も同じ比率で大きくなります。

### 判定の設定

全体の設定ファイルに保存し、全メイド共通です。

| 項目 | 既定値 | 内容 |
| --- | --- | --- |
| teleportDistanceCm / teleportAngle | 20 cm / 45 度 | 1 フレームでこれ以上動き、その速さが毎秒 300 cm / 1000 度を超えたら瞬間移動として即座に合わせる（低 fps のコマ送りは瞬間移動とみなさない） |
| frameStepMax | 0.25 秒 | 一時停止中にモーション時刻がこの秒数以下だけ進んだらコマ送りとして扱う |
| seekTolerance | 0.1 秒 | 再生中にモーション時刻が想定よりこれ以上進んだらシークとして扱う |

範囲外の値は読み込み時に範囲へ丸めます。設定例は `config-example/HaloFollow.xml` にあります。

### 全体の設定

ウィンドウ・その他の設定です。

| 項目 | 既定値 | 内容 |
| --- | --- | --- |
| enabled | true | ヘイロー追従全体の有効化 |
| windowShortcut | Ctrl+Shift+H | 設定ウィンドウの開閉キー。読めない値は既定に戻す |
| windowX / windowY | -1 | ウィンドウの位置（画面のピクセル）。負の値は画面中央 |
| windowWidth / windowHeight | 420 / 600 | ウィンドウの大きさ（画面のピクセル。UI 倍率をかけた後の実サイズ） |
| uiScale | 1 | UI 倍率（0.8〜2）。SceneEditor がある間は SceneEditor の倍率に従う |


## 時間の扱い

追従の時間は、メイドのモーション（AnimationState）の時刻と再生速度から決めます。そのため、SceneEditor を参照せずにタイムラインの操作に合わせられます。

| 状態 | 判定 | 動き |
| --- | --- | --- |
| 再生中 | 再生速度が正で、時刻が想定どおり進む | モーションの時間で追従・浮遊を進める（再生速度 0.5 倍なら追従も 0.5 倍） |
| 一時停止中 | 再生速度が 0 で、時刻が変わらない | 追従と浮遊の位相を止める。頭の姿勢を編集すると、浮遊を保ったまま即座に合わせる |
| コマ送り・連番出力 | 一時停止中に時刻が `frameStepMax` 以下だけ進む | 進んだ時間だけ追従・浮遊を進める |
| シーク・巻き戻し・ループ境界 | 時刻が戻る、または大きく跳ぶ | 現在の頭へ即座に合わせ、速度と浮遊の位相を初期化する |
| モーションなし | 再生中のモーションがない | ゲームの時間で進める |

ゲーム標準の Loop モーションの周回はシークとして扱わず、そのまま追従を続けます。


## 仕組み

ヘイローの SkinnedMeshRenderer が参照するボーン（`Headset`）と同じ親の下に、実行時専用の `HaloFollow_Headset` を作ります。bones の参照だけをこちらへ差し替え、元の `Headset` は目標姿勢として読むだけで動かしません。無効化・装備解除・非表示では bones を元に戻し、`HaloFollow_Headset` は元のボーンと同じ姿勢に戻します。このオブジェクトは装備 1 つにつき最大 1 個で、装備と一緒に破棄されます。

更新は、全 LateUpdate（ゲームの頭の動き・SceneEditor の姿勢更新）の後、スキニングと描画の前に行います。


## 既知の制限

- 髪や頭との接触は回避しません。位置のずれの上限だけでは接触しないことを保証できないため、体型やポーズに合わせて上限を調整してください
- モーションの再生速度が 0、またはモーションが無効になっている間は、SceneEditor 以外でも一時停止として扱い、遅れも浮遊も出ません。次の場合が該当します
  - タイムラインのボーン・IK レイヤーだけで頭を動かす再生（モーションは止まったまま）
  - ゲーム側でモーションを止めた状態
  - 1 回再生のモーションが終わった後
- ボーンルートにアタッチした装備（CRC ボディのアタッチ編集）は対象外です
- 一時停止中に `frameStepMax`（0.25 秒）より大きく時刻が進むと、シークとして扱います。4fps 未満の連番出力では遅れが出ません。逆再生も毎フレームのシークとして扱うため、頭に固定されて見えます
- SceneEditor の「キャラの影」の複製は、作られた時点の bones を写します。追従を有効にする前に複製が作られた場合、影のヘイローは頭に固定されたままになります
- 停止後に小さく弾む表現、タイムラインへの焼き込み、シーンごとの設定保存は未実装です

### プラグイン開発者向け

このプラグインの開発に手伝っていただける場合、下記手順でプルリクエストを送信してください。

1. このリポジトリをフォークします

2. フォークしたリポジトリをクローンし、サブモジュール（UI の部品に使っている [COM3D2.MTEUtils](https://github.com/kidonaru/COM3D2.MTEUtils)）を取得します
```bash
git clone https://github.com/[自分のユーザー名]/COM3D2.HaloFollow.Plugin.git
cd COM3D2.HaloFollow.Plugin
git submodule update --init
```

3. `.env.sample` をコピーして `.env` を作り、COM3D2 と COM3D2.5 のインストール先（`COM3D2_DIR` / `COM3D25_DIR`）を書きます
（COM3D2.5 版のビルドにも COM3D2 側の `Sybaris\lib\UnityInjector.dll` を使うため、`COM3D2_DIR` は常に必要です）

4. コード修正後、デバッグ用ビルドスクリプトを実行し動作確認
(自動で各ゲームの`Sybaris\UnityInjector`内にコピーされます。`com3d2` / `com3d25` を付けると片方だけビルドします)
```bash
.\debug.bat
```

5. 差分をリモートにプッシュして、フォーク元に対してプルリクエストを送信
