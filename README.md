# COM3D2.HaloFollow.Plugin

COM3D2.5 で、頭に固定されたヘイローなどの装備を、頭の動きに少し遅れて滑らかに追従させる BepInEx プラグインです。キャラクターが静止しているあいだは、ヘイローが基準位置を中心に小さく上下に浮遊します。

- ヘイローは一つの剛体として動きます。輪の形・大きさ・材質・描画設定は変わりません
- 位置と回転の追従は、別々に有効化・調整できます
- 位置と角度のずれには上限があり、急な動きでも頭から離れすぎません
- SceneEditor の再生・一時停止・コマ送り・シーク・ループ・連番出力に合わせて動きます
- モデルファイル・SceneEditor の保存内容・頭・髪・他の衣装は変更しません

## 導入

1. BepInEx 5 が導入済みの COM3D2.5 を用意します
2. `COM3D2.HaloFollow.dll` を `COM3D2.5\BepInEx\plugins\` に置きます
3. ゲームを起動し、ヘイロー（初期設定では `natu_halo.model`）を装備したメイドを表示します

## 解除

1. `BepInEx\plugins\COM3D2.HaloFollow.dll` を削除します
2. 設定も消す場合は、`BepInEx\config\com.kidonaru.com3d2.halofollow.cfg` を削除します

モデルファイルは変更していないため、ほかに戻す作業はありません。

## 操作

ギアメニューの「HaloFollow」ボタンか `Ctrl + Shift + H` で、設定ウィンドウを開閉します（キーは設定ファイルの `WindowShortcut` で変更できます）。

SceneEditor が入っていると、設定ウィンドウは SceneEditor のウィンドウと連携します。

- ウィンドウ同士をタブにまとめて（ドッキングして）表示できます
- UI 倍率は SceneEditor の設定に従います

SceneEditor が無い場合は、独立したウィンドウとして動きます。ウィンドウの位置・大きさと UI 倍率は設定ファイルの `[Window]` に保存されます。

- **ヘイロー追従を有効にする**: 全体の切替です。無効にすると、通常の頭への固定追従に戻ります
- **対象**: 追従させる装備のモデル名または menu 名です（例: `natu_halo.model`、`trinity_sweets_halo_z3_hat_i_.menu`）。対象ごとに有効化と調整ができます。追従ボーン名は「適用」で確定します
- **姿勢リセット**: すべての対象を現在の頭の姿勢へ即座に合わせ、追従の速度と浮遊を初期化します
- **この対象を初期値に戻す** / **判定の設定を初期値に戻す**: 各設定を既定値に戻します。スライダー右の「R」は 1 項目だけを既定値に戻します
- **UI 倍率 %**: ウィンドウの拡大率です。SceneEditor がある間は SceneEditor の設定を書き換えます

設定はゲームを再起動せずに反映され、最後の変更から 1 秒後とウィンドウを閉じたときに保存されます。

## 設定項目

### 対象ごと（`[Target.<対象名>]`）

| 項目 | 既定値 | 内容 |
| --- | --- | --- |
| Enabled | true | この対象の追従を有効にする |
| BoneName | Headset | モデルが頭に付くためのボーン名 |
| PositionFollow / PositionTime | true / 0.10 秒 | 位置の遅れ追従。0 秒で即時追従 |
| RotationFollow / RotationTime | true / 0.10 秒 | 回転の遅れ追従。0 秒で即時追従 |
| MaxPositionOffsetCm | 3 cm | 本来の位置からの最大ずれ。遅れと浮遊を合成した結果にかかる |
| MaxAngle | 10 度 | 本来の角度からの最大ずれ |
| OffsetPositionCm / OffsetRotation | 0 | 基準位置・角度の追加オフセット（ボーンのローカル軸） |
| FloatEnabled | true | 静止中の上下浮遊。無効なら基準位置へ収束する |
| FloatAmplitudeCm | 0.5 cm | 浮遊の振幅（片側。全幅はこの 2 倍）。0 で浮遊なし |
| FloatPeriod | 3 秒 | 浮遊の 1 往復の時間 |
| FloatTransitionTime | 0.3 秒 | 動作開始・停止時に浮遊の強さを切り替える時間 |

距離（cm）は頭のスケールに合わせて換算します。体型スライダーで頭を大きくすると、ずれの上限や振幅も同じ比率で大きくなります。

### 判定（`[Detection]`、全対象共通）

| 項目 | 既定値 | 内容 |
| --- | --- | --- |
| StillLinearSpeedCm / StillAngularSpeed | 1 cm/秒 / 5 度/秒 | これ未満の状態が続くと静止とみなす |
| MoveLinearSpeedCm / MoveAngularSpeed | 3 cm/秒 / 15 度/秒 | 静止中にこれを超えると動作とみなす（ヒステリシス） |
| StillDelay | 0.5 秒 | 静止とみなすまでの継続時間 |
| TeleportDistanceCm / TeleportAngle | 20 cm / 45 度 | 1 フレームでこれ以上動いたら瞬間移動として即座に合わせる |
| FrameStepMax | 0.25 秒 | 一時停止中にモーション時刻がこの秒数以下だけ進んだらコマ送りとして扱う |
| SeekTolerance | 0.1 秒 | 再生中にモーション時刻が想定よりこれ以上進んだらシークとして扱う |

設定例は `config-example/com.kidonaru.com3d2.halofollow.cfg` にあります。

### ウィンドウ（`[Window]`）

| 項目 | 既定値 | 内容 |
| --- | --- | --- |
| X / Y | -1 | ウィンドウの位置（画面のピクセル）。負の値は画面中央 |
| Width / Height | 420 / 560 | ウィンドウの大きさ（画面のピクセル。UI 倍率をかけた後の実サイズ） |
| UIScale | 1 | UI 倍率（0.8〜2）。SceneEditor がある間は SceneEditor の倍率に従う |

## ビルド

UI の部品に [COM3D2.MTEUtils](https://github.com/kidonaru/COM3D2.MTEUtils) をサブモジュールとして使っています。クローン後に取得してから `debug.bat` / `release.bat` でビルドします。

```
git submodule update --init
```

## 時間の扱い

追従の時間は、メイドのモーション（AnimationState）の時刻と再生速度から決めます。そのため、SceneEditor を参照せずにタイムラインの操作に合わせられます。

| 状態 | 判定 | 動き |
| --- | --- | --- |
| 再生中 | 再生速度が正で、時刻が想定どおり進む | モーションの時間で追従・浮遊を進める（再生速度 0.5 倍なら追従も 0.5 倍） |
| 一時停止中 | 再生速度が 0 で、時刻が変わらない | 追従と浮遊の位相を止める。頭の姿勢を編集すると、浮遊を保ったまま即座に合わせる |
| コマ送り・連番出力 | 一時停止中に時刻が `FrameStepMax` 以下だけ進む | 進んだ時間だけ追従・浮遊を進める |
| シーク・巻き戻し・ループ境界 | 時刻が戻る、または大きく跳ぶ | 現在の頭へ即座に合わせ、速度と浮遊の位相を初期化する |
| モーションなし | 再生中のモーションがない | ゲームの時間で進める |

ゲーム標準の Loop モーションの周回はシークとして扱わず、そのまま追従を続けます。

## 仕組み

ヘイローの SkinnedMeshRenderer が参照するボーン（`Headset`）と同じ親の下に、実行時専用の `HaloFollow_Headset` を作ります。bones の参照だけをこちらへ差し替え、元の `Headset` は目標姿勢として読むだけで動かしません。無効化・装備解除・非表示では bones を元に戻し、`HaloFollow_Headset` は元のボーンと同じ姿勢に戻します。このオブジェクトは装備 1 つにつき最大 1 個で、装備と一緒に破棄されます。

更新は、全 LateUpdate（ゲームの頭の動き・SceneEditor の姿勢更新）の後、スキニングと描画の前に行います。

## 既知の制限

- 髪や頭との接触は回避しません。位置のずれの上限だけでは接触しないことを保証できないため、体型やポーズに合わせて上限を調整してください
- モーションの再生速度が 0、またはモーションが無効になっている間は、SceneEditor 以外でも一時停止として扱い、遅れも浮遊も出ません。次の場合が該当します
  - タイムラインのボーン・IK レイヤーだけで頭を動かす再生（モーションは止まったまま）
  - ゲーム側でモーションを止めた状態
  - 1 回再生のモーションが終わった後
- ボーンルートにアタッチした装備（CRC ボディのアタッチ編集）は対象外です
- 一時停止中に `FrameStepMax`（0.25 秒）より大きく時刻が進むと、シークとして扱います。4fps 未満の連番出力では遅れが出ません。逆再生も毎フレームのシークとして扱うため、頭に固定されて見えます
- SceneEditor の「キャラの影」の複製は、作られた時点の bones を写します。追従を有効にする前に複製が作られた場合、影のヘイローは頭に固定されたままになります
- 停止後に小さく弾む表現、動作中も続く浮遊、タイムラインへの焼き込み、シーンごとの設定保存は未実装です
